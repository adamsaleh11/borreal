## How each was verified

- **Real, not generated.** Each original carries camera EXIF from a physical
  body (Canon EOS 60D, Canon EOS 7D, Canon PowerShot A2400, Sony HDR-CX350VE,
  Apple iPhone, Huawei), and five of the six were uploaded between 2005 and
  2020, before consumer image generation existed. Commons also requires
  AI-generated work to be tagged as such; none of these is.
- **Location is genuine.** The Canadian frames are Canadian and the Chilean
  frames are Chilean — nothing is captioned as somewhere it was not taken. The
  Rancagua-area candidate was verified by GPS EXIF; the Saskatchewan canola is
  by a Saskatoon photographer.
- **Licence is on the file page**, not inferred from a search result.

## Licence obligations, in short

- **CC0** (`red-lentils.jpg`) — no obligation at all.
- **CC BY 2.0** (three files) — name the photographer and the licence.
- **CC BY-SA 3.0 / 4.0** (two files) — same, plus: if you publish a *modified*
  version of one of these photographs, that modified photograph must carry the
  same licence. This does not affect the rest of the site; only the image.

Files here are cropped and resized from the Commons originals — resizing and
cropping are permitted by all of these licences.
